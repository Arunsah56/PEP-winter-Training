 ## 📘 To Do App (Django Class Based Views) ##

A simple To Do web application built using Django that demonstrates core concepts such as:

1. Django Models
2. One to Many relationships
3. Admin interface
4. Class Based Views (CBVs)
5. URL routing
6. Templates

This project is designed for learning and training purposes.

## 🚀 Features ##

. Create task categories
.  Add tasks under categories
.  Update tasks
.  Delete tasks
.  Mark tasks as completed
.  View tasks grouped by category
. Admin panel for managing data

## 🧱 Tech Stack ##

1. Python 3.x
2. Django
3. SQLite (default Django database)
4. HTML Templates
